## Remediation Priority

**Critical path** (blocks acceptance):
- **#3** (task reminders): notification scheduling missing
- **#7** (Auto-Pilot): no UI toggle, defaults to ON instead of OFF
- **#9** (task relationships): task editor has no relationship links

**High path** (observable gaps in feature completeness):
- **#1** (contact relationships): no company/lead link UI for contacts
- **#8** (error sanitization): risk of credential leakage in error messages

**Medium path** (incomplete but functional):
- **#2** (opportunity pipeline): no workflow UI, but stage and links exist
- **#4** (evidence capture): import works, scoring not visible
- **#5** (audit transcripts): aggregation loses detail
- **#6** (integration preview): PHAROS lacks preview UI

---

## Acceptance Scenario

The scenario in `/goal` command: Record a lead → link to company and contact → add notes and audit findings → create opportunity → schedule follow-up → quit/reopen → context and next action recovered intact.

**Current blockers**:
- Leads cannot link to contacts (ContactEditor has no contact-to-lead relationship)
- Tasks cannot link to opportunities (TaskEditor has no relationship fields)
- Follow-up reminders don't schedule (only on-demand, no trigger)
- Auto-Pilot has no UI (defaults to ON, should default to OFF)

**Next steps**: Fix critical and high items, then run acceptance test in the app.
