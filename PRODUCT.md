# ControlWard

## Register

product

## Users

Martin and the PHAROS workspace owner use a Mac desktop to review relationships,
project commitments, incoming metadata and research signals. The app is currently
single-user. The main home is the existing ContextWard native desktop, as selected
by Martin.

## Product Purpose

Bring ContextWard, Project Control and Email Aggregator into ControlWard. Expand
working functionality throughout the sections. Help the owner find the next
review, connect a record to a project, and see what has actually been saved.
Project decisions remain in the Project Control register; GAP supplies read-only
signals; imported mail is explicitly distinguished from live mailbox sync.

## Brand Personality

Calm, precise, familiar. This working direction preserves the existing PHAROS
amber, ink, logo and native system typography. It is derived from the existing
app and the requested integration, rather than a new brand identity.

## Anti-references

Avoid decorative metric walls, repeated branding that displaces navigation,
all-green connection indicators with no health evidence, and prototype features
presented as live services. These are implementation guardrails for this pass.

## Design Principles

- Put reviewable work before statistics.
- Keep project authority and source provenance visible at the decision point.
- Show the destination and selected data before a capture leaves the Mac.
- Preserve useful native controls and keyboard behavior.
- Treat empty, disconnected and failed states as normal parts of the workflow.

## Accessibility & Inclusion

Use standard macOS controls and accessibility labels. Preserve keyboard access,
respect Reduce Motion and check text contrast. No formal accessibility
certification or full French localization is claimed for this release.
