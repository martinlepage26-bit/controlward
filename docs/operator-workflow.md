# Using ControlWard for daily prospect and follow-up work

Start in **Pipeline**. Import an existing lead CSV, add a lead by hand, or use **Find prospects** to review public business listings. For configured evidence-backed research, use **Pipeline → Leads** and add only Ready records to Pipeline for review. Operations → Import LeadGen accepts exported event files. A listing or imported score is a research lead; it does not establish buying intent.

Open a lead and check its name, source evidence, contact details, service or ask, and next follow-up date. Enter a value only when you have one. Choose **Review conversion…**, check the proposed company, contact, opportunity and follow-up task, then confirm. A business without a named person creates no invented contact. A second conversion reuses its links.

Choose **Write follow-up message**. Read the draft and its recorded facts/unknowns. Apple Intelligence may rephrase it; unsupported output falls back to the grounded draft. Email opens a draft in Mail.app when an address exists. Review recipients and text there before sending. Record the actual follow-up in ControlWard only after it happened.

Use **Tasks** or the lead's next follow-up date to maintain the next action. The converted lead and its follow-up task share the date. Operations → **Schedule reminders** requests notification permission explicitly and reports the result. Until macOS authorization and delivery are confirmed, use the visible Pipeline due list and Tasks list; they work without notifications.

Record Won or Lost when the outcome is known. ControlWard updates the linked opportunity and closes that lead's follow-up task. Pipeline totals count the entered value once and list unvalued records separately. Won value records an outcome you enter; it is not a payment receipt or revenue generated by the application.

Use **Notes** for relationship context and **Email → Local review inbox** for metadata review and one task per message. Synthetic/imported mail without a connected provider cannot perform mailbox actions. **Operations → Lantern audits** keeps separate French and English assessments; **Saved views** is in the profile menu at the top right.

Before significant changes, use Settings → **Save local backup**. Restore previews the native workspace and saves a rollback copy first. The backup excludes Keychain credentials, WebKit module storage and external registers. Export Project Control separately through its Tools menu. Project capture previews the destination and creates an unassigned inbox item; project decisions remain in that register.

For a safe walkthrough from a source checkout, run `bin/preview-controlward`. Its separate preview app uses temporary synthetic data and isolated mail credentials. The production app uses the established ControlWard workspace and configured connectors; opening it is a distinct live-use step.
